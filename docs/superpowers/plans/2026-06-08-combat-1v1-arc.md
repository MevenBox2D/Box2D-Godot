# Combat 1V1 — Arène + Personnage + Arc — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire, dans le projet Godot 4.6 `nouveau-projet-de-jeu`, un combat 1v1 jouable-à-regarder entre deux personnages-cercles physiques (Rapier2D), 100 PV chacun, dans une arène carrée fermée, avec une première arme complète (l'arc : visée, bandage, tir, projectile) qui valide tout le pipeline de combat.

**Architecture:** Scènes Godot indépendantes et réutilisables — `Arena`, `Character` (corps Rapier + PV + signal `died`), `HealthBar` (affichage découplé de la physique), `BowWeapon` (state machine pilotant un `RapierPinJoint2D` en mode Motor Position) et `Arrow` (projectile à dégâts). Une scène `Combat` orchestrée par un script `game_manager.gd` instancie les deux personnages, les arme, écoute leurs morts et déclare le résultat (victoire/match nul).

**Tech Stack:** Godot 4.6, GDScript, plugin `godot-rapier2d` (RapierRigidBody2D, RapierStaticBody2D, RapierPinJoint2D, RapierArea2D), AnimationPlayer.

**Note méthodologique sur les tests :** ce projet n'a pas de framework de tests unitaires GDScript installé (pas de GUT/GdUnit), et la nature du travail — corps physiques, ressenti de combat, animations — se prête mal à des assertions unitaires strictes. Chaque tâche remplace donc le cycle "test rouge → test vert" par un **cycle d'observation manuelle** : lancer une scène isolée dans l'éditeur Godot (F6 / "Run Current Scene"), observer un comportement précis et vérifiable à l'œil (valeur affichée dans la console via `print`, comportement visuel), puis ne committer qu'une fois le comportement attendu confirmé. Cela conserve l'esprit TDD (définir l'attendu avant d'écrire le code, vérifier avant de committer) en l'adaptant au développement de jeu physique.

- [ ] **Step 1: Définir les calques**

Crée le fichier avec un contenu simple regroupant les calques de collision utilisés dans tout le combat (1 = arène/murs, 2 = personnage A, 3 = personnage B, 4 = projectiles A, 5 = projectiles B). Cela évite la duplication de "nombres magiques" dans les scripts à venir et permet à une flèche d'ignorer son tireur (cf. spec §3, anti-auto-collision) :

```gdscript
class_name CombatLayers

const ARENA := 1
const CHARACTER_A := 2
const CHARACTER_B := 3
const PROJECTILE_A := 4
const PROJECTILE_B := 5

## Bit correspondant à un numéro de calque Godot (1-indexé)
static func bit(layer_number: int) -> int:
	return 1 << (layer_number - 1)
```

- [ ] **Step 2: Écrire le script du personnage**

```gdscript
class_name Character
extends RapierRigidBody2D

const MAX_HP := 100

signal hp_changed(current_hp: int, max_hp: int)
signal died

var current_hp: int = MAX_HP
var opponent: Character = null

func take_damage(amount: int) -> void:
	if current_hp <= 0:
		return
	current_hp = maxi(current_hp - amount, 0)
	hp_changed.emit(current_hp, MAX_HP)
	if current_hp == 0:
		died.emit()
```

**Files:**

- [ ] **Step 1: Construire la scène de la barre de vie**

Nœud racine `Node2D` nommé `HealthBar`, contenant un `TextureProgressBar` (ou `ProgressBar`) enfant configuré avec `min_value = 0`, `max_value = 100`, `value = 100`. Place-le à un offset fixe au-dessus de l'origine du `Node2D` (ex. `position = Vector2(-20, -35)` sur la barre, pour qu'elle apparaisse au-dessus du cercle une fois le `HealthBar` positionné sur le personnage).

- [ ] **Step 2: Écrire le script de suivi**

Le `HealthBar` ne doit **pas** être un enfant du `Character` (pour ne pas hériter de sa rotation physique — cf. spec §2, "nœud séparé... repositionné chaque frame... sans copier sa rotation"). Il référence le personnage et se repositionne lui-même :

```gdscript
class_name HealthBar
extends Node2D

@export var target: Character

@onready var _progress_bar: ProgressBar = $ProgressBar

func _ready() -> void:
	if target:
		target.hp_changed.connect(_on_hp_changed)
		_on_hp_changed(target.current_hp, Character.MAX_HP)

func _process(_delta: float) -> void:
	if target:
		global_position = target.global_position

func _on_hp_changed(current_hp: int, max_hp: int) -> void:
	_progress_bar.max_value = max_hp
	_progress_bar.value = current_hp
```

(Adapte le chemin `$ProgressBar` au nom réel du nœud enfant créé à l'étape 1.)

- Un `Sprite2D` pour la représentation visuelle.

Le `RapierPinJoint2D` reliant l'arme au personnage est ajouté **dans la scène du personnage ou du combat** (pas dans `bow_weapon.tscn`, car un joint référence deux corps qui doivent coexister dans le même arbre — voir Task 8 pour le câblage final). Pour l'instant, dans cette tâche, le test manuel instancie temporairement les deux et le joint à la main.

- [ ] **Step 2: Écrire le script de l'arme — squelette de state machine + TRACKING**

```gdscript
class_name BowWeapon
extends RapierRigidBody2D

enum State { TRACKING, DRAWING, FIRING, COOLDOWN }

@export var character: Character
@export var joint: RapierPinJoint2D
@export var time_before_draw: float = 1.5

var _state: State = State.TRACKING
var _state_timer: float = 0.0

func _ready() -> void:
	if joint:
		joint.motor_position_enabled = true

func _physics_process(delta: float) -> void:
	match _state:
		State.TRACKING:
			_process_tracking(delta)

func _process_tracking(delta: float) -> void:
	if character == null or character.opponent == null or joint == null:
		return
	var to_opponent: Vector2 = character.opponent.global_position - global_position
	joint.motor_position_target_angle = to_opponent.angle()

	_state_timer += delta
	if _state_timer >= time_before_draw:
		_state_timer = 0.0
		_state = State.DRAWING  # branché en Task 7
```

## Task 6: Projectile — la flèche

**Files:**
- Create: `nouveau-projet-de-jeu/weapons/bow/arrow.tscn`

- [ ] **Step 1: Construire la scène de la flèche**

Nœud racine `RapierRigidBody2D` nommé `Arrow`, avec :
- Un `CollisionShape2D` (forme `CapsuleShape2D` ou `CircleShape2D` simple).
- Un `Sprite2D` pour la représentation visuelle.
- Un `RapierArea2D` enfant avec son propre `CollisionShape2D` (même forme ou légèrement plus grande), servant de hitbox de détection (cf. spec §3 : signal natif `body_entered`).

- [ ] **Step 2: Écrire le script de la flèche**

```gdscript
class_name Arrow
extends RapierRigidBody2D

@export var damage: int = 10

@onready var _hitbox: RapierArea2D = $RapierArea2D

func _ready() -> void:
	_hitbox.body_entered.connect(_on_body_entered)

func _on_body_entered(body: Node) -> void:
	if body is Character:
		body.take_damage(damage)
	queue_free()

func launch(direction: Vector2, speed: float, owner_layer: int, target_layer: int) -> void:
	rotation = direction.angle()
	linear_velocity = direction.normalized() * speed
	collision_layer = CombatLayers.bit(owner_layer)
	collision_mask = CombatLayers.bit(target_layer) | CombatLayers.bit(CombatLayers.ARENA)
```

(Adapte `$RapierArea2D` au nom réel donné au nœud dans l'éditeur. La fonction `launch` centralise la configuration anti-auto-collision : la flèche ne peut entrer en collision qu'avec l'arène et le calque de l'adversaire — cf. spec §3 "Anti-auto-collision".)

## Task 7: Arme Arc — DRAWING, FIRING, COOLDOWN et tir de flèches

**Files:**
- Modify: `nouveau-projet-de-jeu/weapons/bow/bow_weapon.gd`
- Modify: `nouveau-projet-de-jeu/weapons/bow/bow_weapon.tscn` (ajout d'un `AnimationPlayer`)

- [ ] **Step 1: Ajouter un `AnimationPlayer` à la scène de l'arme**

Dans l'éditeur, ajoute un nœud `AnimationPlayer` enfant de `BowWeapon`. Crée une animation nommée `"draw"` (ex. 0.6 s) qui anime visuellement le `Sprite2D` de l'arc pour mimer la tension de la corde (ex. modification de `scale` ou `frame` si sprite animé, ou simplement un changement de texture à mi-animation — le détail visuel exact est laissable à l'appréciation visuelle, l'important est qu'elle ait une durée mesurable et un signal de fin).

- [ ] **Step 2: Étendre le script avec les états restants**

```gdscript
class_name BowWeapon
extends RapierRigidBody2D

enum State { TRACKING, DRAWING, FIRING, COOLDOWN }

const ArrowScene := preload("res://weapons/bow/arrow.tscn")

@export var character: Character
@export var joint: RapierPinJoint2D
@export var time_before_draw: float = 1.5
@export var cooldown_duration: float = 1.0
@export var arrow_damage: int = 10
@export var arrow_speed: float = 500.0

@onready var _animation_player: AnimationPlayer = $AnimationPlayer
@onready var _nock_point: Marker2D = $NockPoint

var _state: State = State.TRACKING
var _state_timer: float = 0.0
var _frozen_target_angle: float = 0.0

func _ready() -> void:
	if joint:
		joint.motor_position_enabled = true
	_animation_player.animation_finished.connect(_on_animation_finished)

func _physics_process(delta: float) -> void:
	match _state:
		State.TRACKING:
			_process_tracking(delta)
		State.COOLDOWN:
			_process_cooldown(delta)
		# DRAWING et FIRING sont pilotés par animation/instanciation, pas par le temps ici

func _process_tracking(delta: float) -> void:
	if character == null or character.opponent == null or joint == null:
		return
	var to_opponent: Vector2 = character.opponent.global_position - global_position
	joint.motor_position_target_angle = to_opponent.angle()

	_state_timer += delta
	if _state_timer >= time_before_draw:
		_state_timer = 0.0
		_start_drawing()

func _start_drawing() -> void:
	_state = State.DRAWING
	_frozen_target_angle = joint.motor_position_target_angle  # figé pendant le bandage (spec §3)
	_animation_player.play("draw")

func _on_animation_finished(anim_name: StringName) -> void:
	if anim_name == "draw":
		_fire()

func _fire() -> void:
	_state = State.FIRING
	var arrow: Arrow = ArrowScene.instantiate()
	get_tree().current_scene.add_child(arrow)
	arrow.global_position = _nock_point.global_position
	arrow.damage = arrow_damage

	var owner_layer: int = CombatLayers.CHARACTER_A if character.opponent_layer_is_b() else CombatLayers.CHARACTER_A
	# Le calque exact (A ou B) est déterminé par GameManager via _setup_layers (Task 8);
	# ici on délègue le choix à une propriété exportée pour rester découplé :
	arrow.launch(Vector2.RIGHT.rotated(_frozen_target_angle), arrow_speed, projectile_layer, target_layer)

	_state = State.COOLDOWN
	_state_timer = 0.0

func _process_cooldown(delta: float) -> void:
	_state_timer += delta
	if _state_timer >= cooldown_duration:
		_state_timer = 0.0
		_state = State.TRACKING
```

> ⚠️ Note pour l'implémenteur : la ligne `owner_layer = ...opponent_layer_is_b()...` ci-dessus est un brouillon — **remplace-la** par les deux propriétés exportées suivantes, plus simples et explicites, à ajouter en haut du script avec les autres `@export` :
> ```gdscript
> @export var projectile_layer: int = CombatLayers.PROJECTILE_A
> @export var target_layer: int = CombatLayers.CHARACTER_B
> ```
> et simplifie l'appel à :
> ```gdscript
> arrow.launch(Vector2.RIGHT.rotated(_frozen_target_angle), arrow_speed, projectile_layer, target_layer)
> ```
> Ces deux valeurs seront assignées par `GameManager` à l'instanciation de chaque arme (Task 8), pour que l'arme du personnage A tire sur le calque B et inversement.

- [ ] **Step 2: Écrire le `GameManager`**

```gdscript
class_name GameManager
extends Node2D

@onready var _arena: Node2D = $Arena
@onready var _character_a: Character = $CharacterA
@onready var _character_b: Character = $CharacterB
@onready var _bow_a: BowWeapon = $BowA
@onready var _bow_b: BowWeapon = $BowB
@onready var _health_bar_a: HealthBar = $HealthBarA
@onready var _health_bar_b: HealthBar = $HealthBarB
@onready var _result_label: Label = $ResultLabel

var _combat_over := false
var _pending_deaths: Array[Character] = []

func _ready() -> void:
	_character_a.global_position = _arena.get_node("SpawnPointA").global_position
	_character_b.global_position = _arena.get_node("SpawnPointB").global_position

	_character_a.opponent = _character_b
	_character_b.opponent = _character_a

	_health_bar_a.target = _character_a
	_health_bar_b.target = _character_b

	_setup_weapon(_bow_a, _character_a, CombatLayers.PROJECTILE_A, CombatLayers.CHARACTER_B)
	_setup_weapon(_bow_b, _character_b, CombatLayers.PROJECTILE_B, CombatLayers.CHARACTER_A)

	_character_a.died.connect(_on_character_died.bind(_character_a))
	_character_b.died.connect(_on_character_died.bind(_character_b))

	_result_label.visible = false

func _setup_weapon(bow: BowWeapon, character: Character, projectile_layer: int, target_layer: int) -> void:
	bow.character = character
	bow.projectile_layer = projectile_layer
	bow.target_layer = target_layer

func _on_character_died(character: Character) -> void:
	_pending_deaths.append(character)
	# Laisse une frame pour qu'un éventuel double K.O. soit détecté avant de conclure
	call_deferred("_resolve_combat_end")

func _resolve_combat_end() -> void:
	if _combat_over or _pending_deaths.is_empty():
		return
	_combat_over = true
	_bow_a.set_physics_process(false)
	_bow_b.set_physics_process(false)

	if _pending_deaths.size() >= 2:
		_show_result("Match nul !")
	elif _pending_deaths[0] == _character_a:
		_show_result("Victoire du personnage B !")
	else:
		_show_result("Victoire du personnage A !")

func _show_result(text: String) -> void:
	_result_label.text = text
	_result_label.visible = true
```
